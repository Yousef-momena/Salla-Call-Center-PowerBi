Salla Call Center -- Power BI Dashboard

📊 Project Overview

This project is an interactive Call Center Performance Dashboard
built with Microsoft Power BI.

The dashboard analyzes call center operations and helps monitor key
performance indicators (KPIs), including call volume, handling
performance, abandonment, and Average Speed of Answer (ASA).

The project uses Power Query for data preparation and DAX for
calculations and KPI measures.

🛠️ Tools & Technologies

Power BI -- Dashboard development and data visualization

Power Query -- Data cleaning, transformation, and preparation

DAX (Data Analysis Expressions) -- Measures, KPIs, and
calculations

Excel / Tabular Data -- Data source and analysis

📁 Dataset

The dataset contains call center information such as:

Project

Month

Calls Offered

Calls Handled

Calls Abandoned

ASA (Average Speed of Answer)

📌 Main KPIs

The dashboard tracks the following main KPIs:

KPI                                 Description

Total Calls                     Total volume of calls
handled/processed

Handling Rate                   Percentage of offered calls that
were handled

Abandonment Rate                Percentage of calls abandoned
before being handled

ASA                             Average Speed of Answer

Forecasted Calls                Expected call volume

Calls Offered                   Calls received by the call center

Power Query was used to prepare the data before analysis.

The data preparation process included:

Importing the source data

Checking data types

Cleaning and transforming columns

Preparing date and month fields

Handling data consistency

Creating a clean dataset ready for modeling and visualization
